# homebrew-convoy

Custom [Homebrew](https://brew.sh) tap for [Convoy](https://github.com/TheDynamicPunk/Convoy), a native macOS download manager.

## Installation

Install the cask directly using:

```bash
brew install --cask ConfusedG33K/convoy/convoy
```

Or tap the repository first:

```bash
brew tap ConfusedG33K/convoy
brew install --cask convoy
```

## Update

To update Convoy when a new release is available:

```bash
brew update
brew upgrade --cask convoy
```
